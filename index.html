TC-001HIGH PRIORITY

Privacy Policy page

Loading, readability and mobile display

Observed concern

The page may load slowly on PC and is difficult to read or does not display correctly on mobile.

Expected result

The policy should load in a reasonable time and remain readable across supported screen sizes.

Test focus

Page-load behaviour, viewport responsiveness, text wrapping and readability.

Performance · Responsive UI
TC-002MEDIUM PRIORITY

Terms & Conditions

Page loading and responsive layout

Observed concern

The terms page may load slowly or present a layout that is not readable on mobile.

Expected result

Users should be able to access and read the complete terms on desktop and mobile.

Test focus

Navigation, loading, content visibility, scrolling and responsive layout.

Usability · Responsive UI
TC-003HIGH PRIORITY

Registration form

Required-field validation

Observed concern

The form allows a user to proceed to the next page without completing mandatory fields.

Expected result

Submission or progression should be blocked until required fields are completed with valid input.

Test focus

Empty submission, field-level messages, valid data and boundary cases.

Functional testing · Validation
